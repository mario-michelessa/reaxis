# Data Setup

## Directory Layout

The default paths are:

```text
data/
  raw/                         manually downloaded source datasets
  datasets/<dataset>/          flattened UI-ready datasets
  sessions/<session>/          interaction logs and saved artifacts
  secrets/gemini_api_key.txt   optional Gemini credential
  uploads/                     fallback upload destination
outputs/                       generated modeling and post-processing results
```

## Prepared Dataset Contract

Each UI-ready dataset is one directory under `REAXIS_DATASETS_ROOT`:

```text
<dataset>/
  image_0001.jpg
  image_0002.jpg
  metadata.csv
  .cache/
    embeddings_clip.npz
    embeddings_siglip2.npz
    embeddings_clip_raw.npz       optional AxisBayes cache
    embeddings_siglip2_raw.npz    optional AxisBayes cache
    coords_pca2d_clip.npz
    coords_umap2d_clip.npz        optional
    coords_tsne2d_clip.npz        optional
    thumbs/                        generated by the backend
```

```bash
python -m backend.precompute_embeddings data/datasets/MyDataset --methods clip --reduction pca
python -m backend.precompute_embeddings data/datasets/MyDataset --methods clip --raw
```

Model weights are downloaded by their libraries on first use unless already present in the local Hugging Face or Torch cache. The main model IDs are `openai/clip-vit-base-patch32`, `google/siglip2-base-patch16-naflex`, and `facebookresearch/dino:main`.

## Automatic Curated Sources

`backend.import_curated_dataset` can acquire these sources itself:

| preset | acquisition | prepared command |
| --- | --- | --- |
| `stars_hubble` | Hugging Face dataset `Supermaxman/esa-hubble` | `python -m backend.import_curated_dataset --preset stars_hubble --name HubbleStars --limit 1200` |
| `paintings_wikiart` | Hugging Face dataset `huggan/wikiart` | `python -m backend.import_curated_dataset --preset paintings_wikiart --name WikiArt1500 --limit 1500` |
| `imagenette_160` | Fast.ai archive at `https://s3.amazonaws.com/fast-ai-imageclas/imagenette2-160.tgz` | `python -m backend.import_curated_dataset --preset imagenette_160 --name Imagenette1500 --limit 1500` |
| `tiny_imagenet_200` | Stanford archive at `https://cs231n.stanford.edu/tiny-imagenet-200.zip` | `python -m backend.import_curated_dataset --preset tiny_imagenet_200 --name TinyImageNet1500 --limit 1500` |

List every registered preset with:

```bash
python -m backend.import_curated_dataset --list-presets
```

## Ordinal Sources

The ordinal importers do not download restricted or manually distributed datasets. Download each source, extract it under `REAXIS_RAW_DATASETS_ROOT` using the exact relative directory shown below, and then run the corresponding importer.

| key | expected raw directory and required contents | source/access note | prepared output |
| --- | --- | --- | --- |
| `utkface` | `utkface-new/UTKFace/*.jpg` | [UTKFace project](https://susanqq.github.io/UTKFace/); non-commercial research | `UTKFace` |
| `affectnet` | `affectnet/archive (3)/labels.csv`, `Train/`, `Test/` | [AffectNet project access](https://www.mohammadmahoor.com/pages/databases/affectnet/); access conditions apply | `AffectNet` |
| `koniq10k` | `koniq-10k-dataset/512x384/`, `koniq10k_distributions_sets.csv` | [KonIQ-10k DaRUS record](https://darus.uni-stuttgart.de/dataset.xhtml?persistentId=doi:10.18419/DARUS-2435) | `KonIQ10k` |

```bash
python -m backend.import_ordinal_datasets --only utkface affectnet koniq10k
```

```bash
python -m backend.import_expanded_ordinal_datasets \
  --only scut isic2024 messidor2 vindr aadb lamem oasis house
```

The expanded importer defaults to 1,500 images, seed 7, maximum edge 512, CLIP embeddings, and PCA/UMAP coordinates. Pass `--skip-precompute` to prepare images and metadata first.

## Low-Level Ordinal Features

The expanded importer computes deterministic whole-image saturation, brightness, contrast, Laplacian sharpness, warmth, Hasler-Suesstrunk colorfulness, Canny edge density, and excess greenness. It writes raw `low_level_*` values and dataset-specific min-max `_01` columns to `metadata.csv`. See `backend/ordinal_study/low_level_features.py` for exact formulas.

## Verify the Installation

After preparing data:

```bash
make doctor
python -m backend.write_dataset_inventory
```

The inventory command writes the local, generated `data/dataset.md`; that machine-specific inventory remains ignored by Git.
